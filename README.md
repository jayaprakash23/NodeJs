## Module,Export,reqiure

In Node JS, we have a entry point (app.js)in our code. We have other files as well other than app.js. We call the other code which are needs to run with other files. We can imported and use the modules.

`A module in JavaScript is a reusable piece of code that is encapsulated and can be imported or exported between files. In Node.js, each file is treated as a separate module. Modules help organize code, avoid naming conflicts, and promote code reuse.`
